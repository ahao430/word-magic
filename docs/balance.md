# 数值平衡表（Balance）

由 `tests/balance_test.gd` 守卫：任何咒语的**伤害/魔力效率**不得逼近 2.0 上限。

## 定价规则（SpellBalance）

```
cost = 8
     + 伤害 × 系数 × 潜力跳数        # 瞬发 0.4；引导形 0.5（渐近线=2.0）
     + (半径 > 16 ? 半径 × 0.05 : 0)
     + 持续 × 2
     + (速度 > 300 ? 4 : 0)
```

- **潜力计价**：引导形（beam/field/summon）按持续时间能打出的跳数计价——
  堆伤害或堆时长都会等比涨价，结构上不可能突破效率上限
- **跳率单一来源**：`SpellBalance.CHANNEL_TICKS`（beam 0.4s / field 0.5s /
  tornado 0.4s / summon 1.0s），效果节点直接读它——计价与执行永不脱钩
- **龙卷按 3 跳计价**：它自己的击退会把敌人推离判定区（实测 ~1.2s 清场），
  按满跳计价会严重虚高；位移是其本体价值
- 钳制上限（SpellValidator）：伤害 60 / 半径 160 / 持续 5s / 速度 420——
  极值组合也过 2.0 守卫（balance_test 用合法极值逐一验证）

- 玩家：HP 30 / 魔力 100 / 回蓝 2/s（晴日 ×1.5）/ 普攻 6 伤免费 0.35s CD /
  回响 40% 耗 50% 伤 0.8s CD / 无敌帧 0.8s

  风暴狂怒 ×1.25 速度 ×0.7 硬直可叠加
